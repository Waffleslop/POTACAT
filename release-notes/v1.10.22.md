Two days after the first cut, the FT-710 band scope has been confirmed on a real radio, and it has grown: a noise floor, a place inside the JTCAT window and the ECHOCAT FT8 view, and a set of fixes the ECHOCAT mobile team found while building their half.

## 📡 The band scope, confirmed — and everywhere you operate

The first FT-710 owner to update to 1.10.21 reported back the same evening: **it works**, spots and all. The layout of what the radio sends was never checked against a real one before that message; it is now. Thank you.

What he asked for next, and what came of it:

- **A noise floor.** A **Floor** slider on the Band Scope window and on ECHOCAT Web's Scope tab. Slide it up and everything below that level draws black, so only the signals show. It changes the picture, never the radio, and it remembers where you left it.
- **The same floor on the JTCAT waterfall.** Gear > Display, next to the speed setting. Display only — decoding is untouched.
- **The band scope inside the JTCAT window.** Gear > Display > **Band scope strip** puts the radio's own spectrum above the audio waterfall, with the dial marker and click-to-tune. The option appears only when your rig can do it.
- **The band scope inside ECHOCAT Web's FT8 view.** A **BS** button beside WF puts the same strip above the FT8 waterfall.
- **ECHOCAT for iOS and Android has it too**, as of the mobile team's release this weekend: a Band Scope section in the VFO tab and the same BS strip in the FT8 view. Tap to tune.

The helper that reads the radio runs only while some window is showing the scope — the Band Scope window, the JTCAT strip, or a connected ECHOCAT client — and stops when the last of them closes.

## 🔧 Fixes from the mobile team's review

Building the mobile half, they read the desktop source and found four things worth fixing. All four are in.

- **Your PC's file path no longer goes to ECHOCAT clients.** The scope's status message carried the helper's absolute path, which on Windows includes your username. Clients now get exactly the fields they need.
- **A phone that drops off no longer leaves the scope running.** The subscription ends with the connection, so the helper — and the radio's SCU-LAN10 setting, if POTACAT turned it on — are released.
- **A Guest Pass cannot change the radio's menu.** A guest can watch the scope; turning SCU-LAN10 on is the host's to do. The guest's card says so instead of offering a button that would do nothing.
- **The synthetic test signal now reaches every client on any rig**, which is how the mobile app could finally be checked against a live picture without an FT-710 in the room.

Also: tapping the scope now snaps to a step that suits the span — 10 Hz at 10 kHz, 500 Hz at 1 MHz — on every client alike, so a tap means the same frequency on the desktop, the web and the phone.
