**Headline:** POTACAT now decides what counts as DX the way you do: another country by default, or farther than a distance you set, with a DX tag and a "DX only" filter on the spot list. Radios behind an external RF-sense tuner get a real tune carrier, a Yaesu tuned to VFO B stays on VFO B, and audio devices that come back under a new ID after a re-plug or Windows update are found again by name. A long list of field fixes rounds it out.

## Spots

- **What counts as DX.** A station in a different country (DXCC entity) from yours is DX; that needs no setup. If you would rather judge by distance, Settings > Spots > Spot Filters has **DX means farther than**, one box for HF and one for 6 m and up, in your own miles or km. A spot that counts gets a yellow **DX** tag, and the Spots button > Filters has **DX only**. ECHOCAT Web has the same tag and filter. Thanks G4BFG.
- **The DX Cluster is labelled Cluster.** "DX" on a spot used to mean only that it came from the cluster feed, so a station one country over looked like DX and a far-away activator did not.
- **The SWL/HF Net Directory is always on.** It no longer needs a setting, and phones on ECHOCAT now receive it instead of waiting on "Waiting for directory data". Open it from More > SWL/HF Net Directory.

## Radios

- **External tuners get a real carrier.** With External ATU type set to **LDG / MFJ (RF-sense auto-tuner)**, the ATU button used to put the radio in CW and transmit with the key up, so nothing came out. The tune carrier is now sent in AM, which needs no key and no audio. Thanks N8JMS.
- **Power On and Power Off in the VFO window.** Scroll to the bottom of the VFO window for a Radio row. Power Off asks for a second press. It shows for every radio that can be switched over CAT, even while the radio is off, and works from a laptop driving a remote shack. Thanks KQ5O.
- **Yaesu VFO B.** On the FT-710 and other Yaesus that report their active VFO, a tune while you are on VFO B now lands on VFO B.
- **Icom transmit power meter.** Icoms on a direct CI-V connection, such as the IC-7200, now show forward power while transmitting.
- **Radios keyed by the audio interface.** The Serial CAT rig editor has **Transmit (PTT)**: choose **The audio interface keys it (SignaLink, the radio's VOX)** and POTACAT no longer keys the radio over CAT on top of the interface.
- **A Yaesu that does not answer.** With **RTS line** on Auto, a Yaesu that stays silent with RTS held low (its CAT RTS menu is on) is tried with RTS/CTS flow control, and kept on it only if it answers.
- **FT-450 Test Connection** no longer reports a failure on a radio that is answering.
- **FLRig:** a server that sends a reply POTACAT cannot read no longer closes the app, POTACAT asks flrig which commands it offers before using any, and one missing command no longer switches the others off. Thanks WG9I.

## Audio

- **Audio devices are found again by name.** When Windows or macOS hands your radio's sound card a new ID (another USB port, a driver update, security software resetting POTACAT's storage), POTACAT now picks the device with the same name, saves it, and says so in the log, instead of leaving the boxes in Settings > My Rigs > Audio blank and refusing to transmit. It never picks a different device. Pick your devices once on this version so their names are recorded. Thanks AE5JE.
- **Bug reports say whether settings are being saved.** A new "Settings saved" line shows when settings last reached disk and, if a save failed, why. Security software that blocks POTACAT's folder (Bitdefender's Safe Files is one) makes every change last only until POTACAT closes; now the report says so.

## FT8 / JTCAT

- **WSPR beacon: the first slot transmits.** Arming the beacon promises a transmission in the next even-minute slot; that promise was used up on the slot already under way, so the first real slot took the random draw and the radio often never keyed.
- **The FT8 decoder is no longer restarted while there is no audio.** With no audio coming in, POTACAT took the idle decoder for a hung one and restarted it every 37 seconds. Thanks W4DLG.
- **A missing audio input on a non-Flex radio** no longer gets SmartSDR and DAX advice. Thanks W4DLG.
- **The JTCAT map pop-out draws the QSO arcs** to and from your station, as the map in the JTCAT window does. Thanks KJ5NVM.

## Activations

- **A park-to-park with a 2-fer.** In the activation log, type the other activator's parks into the park box separated by commas (US-1234, US-5678) and each park gets its own contact. Before, a list like that logged the contact with no park at all; anything that is not a park reference now stops the log and says why. Thanks WD3D.

## Windows

- **No window can be shrunk past its own controls.** Every window has a minimum size now. Thanks N0KAH.
- **The Conditions window remembers its size and position**, including a narrow strip on a second screen and a window left maximized. Thanks W9TEF.
- **The Worked All States table scrolls.** Thanks N0KAH.
