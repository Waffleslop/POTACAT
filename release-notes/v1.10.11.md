A new parks program joins the spot table, FT8 hunting gets a real memory policy instead of "worked once, skipped forever", and a batch of field reports get their fixes: the frozen dial-following mystery, the idle receiver grabbing your radio the moment you stop operating, and the IC-7300 tune button that never tuned.

## 🏞️ New spot source: PARC-Community

**PARC** (Protected Area Radio Community, parc-community.com) — a POTA-style parks program with 217,000+ parks worldwide — is now a spot source. Turn it on in the spots panel or Settings (off by default), and PARC activations appear in the table and on the map in their own green, with links to the park pages. Receive-only for now: PARC doesn't publish a spotting API yet, so there's no re-spot after a QSO. Requested by a user — thanks Jeff.

## 🔁 FT8 "worked before" learns some manners

Three changes for the Hunt and Auto CQ modes, driven by a sharp user report:

- **Bug fix:** Hunt's dupe check was blocking on *any* prior contact, ever, on *any* band or mode — a months-old 20m contact silently blocked that station on 40m. It now correctly considers only the same band and mode.
- **Rework window:** a new "Worked-before expires after N days" setting in the JTCAT gear menu. Set 30 and anything older stops counting. 0 (the default) keeps today's never-expire behavior.
- **Park awareness, automatic:** if a station is currently spotted as an activator, you're only skipped if you already worked them at that same park, on that band and mode, today — which is exactly how the programs count credit. Yesterday's contact activating a new park today gets called.

Manual double-click replies were never blocked and still aren't — the warning toast now explains itself when an old contact doesn't count anymore.

## 📻 rigctld round 3 — and the IC-7300 tune button

The third round of fixes from one user's extraordinary control-by-control test matrix (issue #82):

- **ATU tune actually tunes.** On hamlib rigs the button only ever *enabled* the tuner — it never started a tune cycle. It now sends the real one-shot, so "auto tune" works on the IC-7300 and friends via rigctld.
- AGC levels map correctly both directions (off/fast/mid/slow), monitor gain, RIT state, and inline-tuner state all read back from the radio, and preamp/attenuator readback no longer trips backends that refuse the query.

## 🎛️ The dial-following freeze, solved

The "rig control works one way" report: computer-to-radio fine, but spinning the radio's dial updated nothing — desktop or mobile — until you touched the app. Cause: the 20-minute idle power-saver pauses radio polling, and the radio's dial can't reset the idle timer *because the poll that would notice it is the thing that got paused.* Polling now never pauses while the VFO window is open or a mobile device is connected — it only pauses when nobody is watching. The pause also logs to the session log now, so it can never hide from a bug report again.

## 🤖 Auto-RX waits its turn

If you use the idle receiver (SSTV / WSPR / PSK31 / JS8 on idle), it could grab the radio 30 seconds after you halted an FT8 run — the idle countdown had quietly expired *during* your session. An active JTCAT session now counts as you being at the radio, so after you stop, Auto-RX owes you the full idle threshold before it starts. Also fixed: the SSTV day/night band switch no longer retunes a JS8 idle session.

## 📡 2m FT8/FT4/FT2

The band list in the JTCAT pop-out gains 2m (144.174 FT8 and friends) for meteor scatter, tropo, and contest weekends.
