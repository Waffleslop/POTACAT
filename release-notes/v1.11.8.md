**Headline:** Two radio fixes. A radio that copies the Kenwood TS-590's commands no longer transmits the moment POTACAT connects, and the Yaesu FTDX3000 / FTDX5000 generation tunes again.

## Radios

- **A TS-590 lookalike no longer keys on connect.** 1.11.7 turned on RTS/CTS flow control for the TS-590S/SG model, which holds the serial port's RTS line high. Radios that copy the TS-590's commands but key PTT on RTS (the FX4CR on F5BUD firmware) transmitted as soon as POTACAT connected. The rig editor gains an **RTS line** choice (Auto, Held low, RTS/CTS flow control). If the radio reports transmit right after connecting and POTACAT did not key it, POTACAT switches that rig to Held low by itself and says so. Thanks SP5GB.
- **FTDX3000, FTDX5000, FT-2000 and FT-450 tune again.** These radios take an 8-digit frequency command and POTACAT sent the 9-digit form newer Yaesus use, so the dial read fine and every tune did nothing. POTACAT now also follows the width the radio itself answers with, so a Yaesu set up as a neighbouring model still tunes. **FTDX5000** is in the radio list. Thanks MM0TWX.
