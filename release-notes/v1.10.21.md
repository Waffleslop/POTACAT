The FT-710 has a real band scope, and it sends it out over the same USB cable POTACAT already uses for CAT and audio. This release reads it: a **Band Scope** window on the desktop and a **Scope** tab in ECHOCAT, showing the radio's own spectrum and waterfall, with your spots overlaid and click-to-tune.

This is a first cut, and it is honest about that. Everything on POTACAT's side has been built and tested end to end, but nobody on the project owns an FT-710, so the one thing that has not been checked against a real radio is the exact layout of the data the radio sends. **If you have an FT-710, you are the test.** Read on for what to install and what to send back.

## 📡 Band Scope for the FT-710

- **More menu > Band Scope** opens a window with a spectrum trace, a scrolling waterfall, your POTA / SOTA / cluster spots drawn at their frequencies across the top of the waterfall, and a red marker on your dial. Click anywhere on the trace or waterfall to tune there; click a spot label to tune to it. The span follows the radio: change it on the front panel and the axis rescales.
- **ECHOCAT gets a Scope tab** on the web client when the shack's active rig is an FT-710. Same picture, same tap-to-tune, at a rate a mobile connection is happy with. The mobile app will follow.
- **The menu item appears only when your active rig is an FT-710.** Everyone else's More menu is unchanged.

### What you need to install, once

POTACAT reads the scope through a small helper program included in this release. The helper talks to the FT-710 through FTDI's driver library, which the radio's own USB driver package does not include.

1. **Windows:** install **LibFT4222** from FTDI — https://ftdichip.com/software-examples/ft4222h-software-examples/ — alongside the Yaesu FT-710 USB driver you already have. **Linux:** FTDI's LibFT4222 for Linux, then `sudo ldconfig`. macOS is untested.
2. On the radio, turn on **OPERATION SETTING > GENERAL > SCU-LAN10**. That is the setting that makes the radio stream its scope. You do not need the SCU-LAN10 box, only the menu item. The Band Scope window offers a button that sets it for you over CAT, and POTACAT turns it back off when you close the window.

If either is missing, the window says exactly which, and what to do. It never sends you into the radio menu when the problem is on the PC.

### What to send back

The first thing this release needs is one capture from a real radio. Open the Band Scope; if it draws something sensible, say so on GitHub issue #91. If it draws nonsense or nothing, run the helper by hand for ten seconds and attach the file to that issue:

```
"C:\Program Files\POTACAT\resources\bin\yaesu-scope.exe" --fps 30 > capture.bin
```

That file is the exact stream from the radio, and it settles the layout question for everyone.

### A note on what was checked

The community write-ups this work started from named a CAT command, `EX040101`, as the one that turns the scope output on. On the FT-710 that menu number is **MY CALL** — sending it as a set would have written "01" over your callsign display. Every command POTACAT sends here was taken from Yaesu's own CAT reference instead, and the code refuses those two commands outright. The only thing POTACAT will change on your radio is SCU-LAN10, only when you press the button, and it puts it back.

## 🔧 Also in this release

- **Custom CAT buttons can read the radio's reply.** Behind the scenes, the Kenwood/Yaesu and Hamlib links gained a way to send a raw command and get its answer back; the scope uses it to read span and mode. Nothing changes for existing buttons.
