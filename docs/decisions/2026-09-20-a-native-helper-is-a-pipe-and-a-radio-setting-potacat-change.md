# A native helper is a pipe, and a radio setting POTACAT changes is a setting POTACAT restores

Recorded 2026-09-20. Moved verbatim from the desktop CLAUDE.md on 2026-11-09; the original is archived in the potacat workspace at docs/history/CLAUDE-desktop-2026-11-09.md.

**A native helper is a pipe, and a radio setting POTACAT changes is a setting POTACAT restores** (FT-710 band scope, 2026-09-20). The scope helper (`helpers/yaesu-scope`) knows nothing about what the bytes mean: it keeps the SPI stream aligned and forwards frames, so the protocol lives in tested JavaScript and a wrong offset is a one-line fix, not a rebuild on three platforms. It loads FTDI's closed-source library at run time, so a missing driver is exit code 2 with the download named — the diagnostics ladder says WHICH piece is missing (library / device / SPI / silent radio / lost bridge / no sync) and never sends the operator into the radio menu on a build that cannot open the bridge. The helper runs only while someone is watching (pop-out open or ECHOCAT subscribed) and is stopped with stdin-close so it can `FT_Close` cleanly. **A community write-up named `EX040101` as "enable scope output"; on the FT-710 that menu is MY CALL** — every CAT command here was checked against Yaesu's CAT reference before a line was written, and the guard in `test/yaesu-scope-test.js` refuses those two commands in main.js. `lib/scope-axis.js` is one copy of the axis maths for three surfaces. The main-window `ReferenceError` lesson from the build: a throw inside an IPC handler is POTACAT's synchronous crash dialog, which presents as a frozen main process with zero CPU.
