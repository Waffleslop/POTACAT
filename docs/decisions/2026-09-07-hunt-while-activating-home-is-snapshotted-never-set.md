**Hunt while activating: home is snapshotted, never set** — Bob N7FQT / Dean N7VBN, 2026-09-07. Most of it already shipped (`toggleActivatorSpots()` revealed the hunter table in a persisted split; the spot-row click already called `fillActivatorFromSpot()` and tuned) — what was missing was Clear, a way back, and discoverability. `window.api.tune()` is a shared sink with no intent, so rather than tag every caller the excursion hangs off the ONE unambiguous gesture: `captureActivatorHome()` is the **first statement** of `fillActivatorFromSpot()`, inheriting the `activationActive` gate from both call sites and running before the mode select is overwritten. An intentional QRG change therefore needs no detection — it is the *absence* of an excursion. `if (activatorHomeFreqHz) return` is the entire answer to three P2Ps in a row. **Only the ±500 Hz arrival check in `onCatFrequency` clears home**: the tune can be refused (VFO lock `main.js:27698`, no rig `:27729`, Guest Pass `:22529`), and an optimistic clear would make the chip vanish while the radio never moved, silently taking away the operator's only way back — confirming arrival makes every failure degrade to "the chip stays up". `activatorFreqHz` (raw) exists because `activatorFreqKhz` is rounded and would return an SSB station on 14285.5 to 14286.0. **Clear empties the form and never moves the radio** (every other control in that row is a text field; an operator fixing a typo mid-listen must not have the rig walk away), while the return chip does both — so "abort everything" is one button and it is the one labelled with the frequency. The chip lives in `#activator-quick-log`, never in the spots panel, because closing the panel is often how an operator signals "done hunting". Fixed alongside: `hunterParkRefs` was reset only on the log success path, so clicking a P2P spot, not working them, then logging your next CQ caller **exported a false park-to-park credit** (the real reason Clear matters); the `+N` badge and autocomplete dropped `program`; `isActivatorDupe()` compared `c.frequency`/`c.timestamp`, fields no contact has ever carried (they are `freqDisplay`/`timeUtc`/`band`), so it degraded to same-call-same-mode-any-band; and self-spot read `activatorFreqKhz` **and** the mode select, so pressing Spot while off-home told every hunter to pile onto the other activator's frequency.
