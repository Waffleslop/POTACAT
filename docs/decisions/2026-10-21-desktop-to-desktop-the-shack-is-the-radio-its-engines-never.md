# Desktop-to-desktop: the shack is the radio, its engines never move

Recorded 2026-10-21. Moved verbatim from the desktop CLAUDE.md on 2026-11-09; the original is archived in the potacat workspace at docs/history/CLAUDE-desktop-2026-11-09.md.

**Desktop-to-desktop: the shack is the radio, its engines never move** (2026-10-21, Ride1226: a paired laptop showed HOLD TO TALK with every rig control dark; spec + decisions: `docs/remote-desktop-parity-spec.md`). Remote MODE (`isRemoteMode()` = an active connection target) is separate from the LINK (`isRemoteLinked()`): every local-rig guard keys off the mode (a reconnecting shack must not let this PC open its port), every send needs the link and says so when it is down (`refuseRemoteNotLinked`). The shack's state comes in through `lib/remote-rig.js`; every PTT source goes through `handleRemotePtt` → `keyRemoteShack` (mic track + `ptt`), and the shack's `ptt-timeout`/`ptt-force-rx`/`ptt-refused` release every PTT button here. FT8/WSPR/PSK/JTTY, CW (text + the local paddle as timed `cw-key` elements), voice macros (the SHACK's recordings) and the band scope run on the shack; the laptop's windows are screen and keyboard (`lib/remote-bridge.js`; the JTCAT pop-out captures NO audio in this mode — a stand-in analyser serves the shack's `jtcat-spectrum` bins to the unchanged waterfall loop). QSOs come back through `qso-attributed` into this desktop's log; a laptop activation is pushed to the shack (`set-activator-park`, now with `end`) because the shack's engines build the records. A desktop driving a shack refuses its own ECHOCAT devices (no chaining). **Multi-client** (`settings.echocatMultiClient`, default off): the owner's devices share the shack (`_clients` in remote-server.js, `_admitClient`/`_onClientGone`; `_sendToAll` replaced every `_sendTo(this._client, …)`), PTT belongs to whoever keyed, replies go to the asker (`_replyWs`), forwarded QSOs/log errors to the last operator ONLY (`sendToActor` — to all, one contact was logged per device), audio to the last device that asked (`audio-moved`); a Guest Pass is never shared. Tests: remote-rig-test, remote-bridge-test, remote-multi-client-test (real sockets). Mobile handoff: potacat-app `docs/desktop-handoffs/multi-client-and-desktop-to-desktop.md`.
