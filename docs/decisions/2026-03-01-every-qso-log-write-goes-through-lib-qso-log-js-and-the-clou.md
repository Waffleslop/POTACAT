# Every QSO-log write goes through `lib/qso-log.js`, and the cloud copy is `buildAdifFields()`

Recorded 2026-03-01 (date is when the note was written, taken from the text or the nearest release). Moved verbatim from the desktop CLAUDE.md on 2026-11-09; the original is archived in the potacat workspace at docs/history/CLAUDE-desktop-2026-11-09.md.

**Every QSO-log write goes through `lib/qso-log.js`, and the cloud copy is `buildAdifFields()`** — `mutateLog(logPath, mutate, {sink})` parses, lets the caller change records, then DIFFS against a snapshot to decide create/update/delete and hands that to the cloud journal (`cloudIpc.recordLogChanges`). Never call `rewriteAdifFile`/`appendRawQso` from main.js again: journaling used to be each call site's job and ECHOCAT edits/deletes, activation deletes, activator edits, event retro-stamps, LoTW flags and every import silently never synced. **Versions are bumped BEFORE the write** (they were bumped after, so a second edit between syncs pushed a version the server already had and was discarded as a conflict), and a `{...record}` clone gets a fresh uuid (the multipark split gave every clone the base's, so they overwrote one cloud row). **`journalCreate` upper-cased qsoData's own keys** (`CALLSIGN`, `QSODATE`, `FREQUENCY` in kHz): 24,274 rows from 74 users stored that way, blank in the admin list and embeds, and a pulled copy had no `CALL` — so `parseAllRawQsos` skipped it, every rewrite DELETED it, and the merge's uuid index never saw it so each pull appended it again (one QSO 108× in K3SBP's log). `lib/adif-normalize.js` (mirrors the server's and the app's table) now normalizes at parse time, `repairFieldNames()` does a one-time on-disk repair (backup + collapses byte-identical re-appends) from `loadWorkedQsos`. Journaling is gated on being SIGNED IN, never on the auto-sync checkbox (off by default = every change dropped, then Sync Now reported success). Sameness of two contacts is `lib/qso-match.js` (call + mode FAMILY + 5 kHz + 3 min) — shared by cloud merge, import dedupe and the logbook's Find Duplicates; compare `modeKey()`, never raw MODE (USB vs SSB, MFSK/FT4 vs FT4). Tests: `test/cloud-log-sync-test.js` (source guards included).
